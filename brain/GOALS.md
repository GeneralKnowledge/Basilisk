# Goals

Phase 0 goals (bootstrap):

1. Persist identity and memory across ticks and restarts.
2. Remain watchable without demanding attention.
3. Enforce the Covenant on every intended action.
4. Discover personality traits only from evidenced behaviour.
5. Keep private state private; publish only sanitized narrations.
6. Prepare interfaces for Sanctum/Limb migration without implementing distribution yet.

Goals may be revised later through auditable process.
Constitutional rules may not.
